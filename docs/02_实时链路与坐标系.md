# 实时链路与坐标系

## 输入

SolarXR 使用 ws://127.0.0.1:21110。每个 tracker 提供 raw quaternion、reference-adjusted quaternion 和去重力线性加速度。

- quaternion 顺序：x,y,z,w
- 加速度单位：m/s²
- 加速度没有设备时间戳，录制使用 Python 主机接收时间

## 特征

方向使用 rotationReferenceAdjusted，手臂 tracker 额外使用左右 Z ±90° 偏置。Server 到 SMPL 使用 diag(-1, 1, -1)。

每帧模型输入为：

    5 个加速度 / 30
    + 5 个 3x3 方向矩阵
    = 60 个 float

模型窗口为 45 帧，输出索引为 40，固有延迟为 4 帧，30 FPS 下约 133 ms。

## 输出

Python 将 SMPL 局部旋转矩阵转换为 Unity quaternion，通过 127.0.0.1:21200 发送。Unity 先恢复 SMPL 全局旋转，再叠加 Avatar bind pose 的全局旋转。
