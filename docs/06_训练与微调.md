# 训练与微调

训练和微调是历史支持流程，不是当前运行时入口。训练源码已从当前工作树移除，但数据、结果和 checkpoint 仍保留用于复现和比较。

当前 ours 多动作 finetune 结果位于：

    results/ours_multi_finetune/

训练前必须确认：

- tracker label 顺序与 wrists_shanks_waist 一致；
- 加速度单位和 /30 缩放一致；
- 方向矩阵使用相同坐标转换；
- 训练结果有明确的 capture、checkpoint 和 metrics 对应关系。

当前需要运行训练时，应从 Git 历史恢复训练脚本和配置，不要把它们与实时 Python 桥接混用。
