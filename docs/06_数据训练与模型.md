# 数据、训练与模型

MobilePose 使用 5×9 orientation + 5×3 acceleration = feature[60]。实时路径必须保持 Tracker 顺序、四元数 xyzw、单位、/30、重采样和腕部轴变换一致。

保留 data/raw/ours、data、results/ours_multi_finetune、checkpoints 和 recordings。主 checkpoint 是 results/ours_multi_finetune/layouts/wrists_shanks_waist/model_finetuned.pth。

OURS 是真实数据，但实时 SolarXR 仍可能在安装点、reset、采样和动作分布上有域偏移。严格比较显示姿态输入几乎一致、加速度差异很小，因此当前问题主要不是 heading 流程；五 IMU 对未观测关节的多解是主要限制。

后续训练应增加真实 SlimeVR 五 IMU 数据、安装角度和标定误差增强，以及蹲、跪、躺、死虫和踢腿动作。离线 heading 研究可以保留，但不属于当前实时启动流程。
