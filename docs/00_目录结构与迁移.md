# 目录结构与迁移说明

项目文档统一存放在 `docs/`，阅读入口为 [`docs/README.md`](README.md)。第三方组件自带的 README、LICENSE 和 CHANGELOG 保留在组件原目录。

## 当前主入口

- 实时：mobileposer.cli.realtime.run
- 回放：mobileposer.cli.replay.recording
- 输入比较：mobileposer.cli.analysis.compare_inputs
- 微调：mobileposer.cli.training.finetune

## 现有实现位置

当前实现暂时保留在 mobileposer/realtime/，统一 CLI 通过薄包装调用它们。这样可以先改变用户入口和文档，再逐步拆分内部模块，不会同时改变 WebSocket 协议和模型输入。

## 非主线代码

以下内容保留用于历史复现，不属于实时启动依赖：

- mobileposer/camera_fusion.py
- mobileposer/camera_fusion 相关脚本
- mobileposer/mobile_export.py 的 Android/ONNX 导出部分
- mobileposer/live_demo.py
- 根目录的一次性数据生成、视频合并和审计脚本
- SlimeVR-Server 和 IMUTrack-for-Spine Unity 工程

## 迁移原则

1. 先保留旧模块路径，确保已有结果仍可读取。
2. 新代码只依赖 mobileposer/core 的公共契约和 realtime 的运行时接口。
3. 只有确认没有调用方后，才把旧模块移动到 archive。
4. data、checkpoints、results 不因为结构整理而删除。
