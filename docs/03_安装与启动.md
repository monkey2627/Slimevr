# 安装与启动

## 环境

使用：

    conda activate mobileposer

验证：

    python -c "import torch; print(torch.__version__)"

## 推荐启动

    python -m mobileposer.cli.realtime.run --config configs/realtime/default.yaml --checkpoint results/ours_multi_finetune/layouts/wrists_shanks_waist/model_finetuned.pth

启动前确认 SlimeVR 已连接并完成 tracker 绑定。不要同时运行多个 realtime bridge，也不要在 Unity 中挂载多个 MobilePoserPoseSource。
