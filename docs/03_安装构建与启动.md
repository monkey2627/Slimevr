# 安装、构建与启动

## Python 环境

使用 `mobileposer` conda 环境运行实时程序。

## SlimeVR 本地构建

本机已验证 JDK 17、CMake、pnpm、Visual Studio 2022 C++ x64/x86 和 Windows SDK 10.0.22621.0。

```powershell
.\SlimeVR-Server\scripts\build-windows-local.ps1 -ValidateOnly
.\SlimeVR-Server\scripts\build-windows-local.ps1
```

成功后应用目录为 `SlimeVR-Server\gui\dist\artifacts\win\win-unpacked\`，应包含 `SlimeVR.exe`、`slimevr.jar`、`SlimeVR-Bindings-Provider.exe` 和 `openvr_api.dll`。

## 启动顺序

1. 启动本地编译的 SlimeVR。
2. 完成 mounting orientation、T-pose 和必要 reset。
3. 绑定 `LEFT_LOWER_ARM`、`RIGHT_LOWER_ARM`、`LEFT_FOOT`、`RIGHT_FOOT`、`WAIST`。
4. 启动 Python，再打开 Unity AvatarScene。
5. 浏览器打开 `http://127.0.0.1:8765/`。

## 当前启动命令

```powershell
D:\Software\anaconda\envs\mobileposer\python.exe -m mobileposer.realtime.run `
  --checkpoint "<root>\results\ours_multi_finetune\layouts\wrists_shanks_waist\model_finetuned.pth" `
```
