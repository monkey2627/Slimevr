# 精度排查流程

1. 检查 layout、tracker 左右绑定、mounting calibration 和 T-pose。
2. 比较实时输入和 results/ours_multi_finetune 中的 ours 输入分布。
3. 用 JSONL 回放验证实时与离线特征、模型输出一致。
4. 单独查看 Python SMPL 输出，不启用 Unity 后处理。
5. 只有 Python 输出合理后，才验证 Unity bind pose 和骨骼轴向。
6. 最后才评估 anchor、地面校正、膝盖保护和 IK。

五 IMU 对髋、膝、肩和肘没有直接观测，跪姿、躺姿和死虫动作出现多解是模型能力边界，不应直接归因于 Unity。
