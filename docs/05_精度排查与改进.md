# 精度排查与改进

SolarXR、WebSocket 和 Unity 接收已不是主要瓶颈。Python heading 与 Server adjusted 的同帧输出通常非常接近；Server adjusted 每帧计算，修正状态通常固定，但 reset、Stay Aligned、漂移补偿和 smoothing 可使其随时间变化。

五 IMU 无法直接观测髋、膝、肩、肘；脚踝安装点与训练数据存在域偏移；微调动作和样本不足；跪、躺、手撑地等姿态具有多解性；模型约有 4 帧、133 ms 延迟。

改进顺序：检查绑定和 mounting orientation；比较 Server 字段与 feature[60]；确认 Python SMPL 是否已经错误；若错误再增加真实五 IMU 数据、安装角度增强和跪/躺/踢腿动作；若 Python 正确而 Unity 错误，再检查 Humanoid 轴和 Avatar 骨长；最后逐项加入 IK、限位和接触约束。

Stay Aligned 和 drift compensation 应一次只测试一项。
