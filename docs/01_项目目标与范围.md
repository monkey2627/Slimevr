# 项目目标与范围

## 当前核心目的

本项目用于研究和验证五个 SlimeVR IMU 在实时人体姿态估计中的可用性。主问题不是继续堆叠 Unity 约束，而是定位误差发生在输入、模型还是重定向。

## 当前主线

    SlimeVR -> SolarXR -> 输入校准 -> MobilePose
             -> SMPL 24 关节 -> WebSocket -> Unity Avatar

当前唯一基线布局是 wrists_shanks_waist，checkpoint 是 results/ours_multi_finetune/layouts/wrists_shanks_waist/model_finetuned.pth。

## 当前不做

- 不把 tracker 绝对旋转直接当作 Avatar 骨骼旋转。
- 未确认模型输出前，不加入新的 IK、膝盖方向约束或骨骼长度约束。
- 不把 camera fusion、Android 导出和历史实验当作实时主线。

## 成功标准

- SolarXR 输入可记录并离线回放。
- 实时和离线特征逐帧一致。
- 能分别观察 Python SMPL 输出和 Unity 重定向结果。
- 每次精度结论都有可复现的录制文件和报告。
